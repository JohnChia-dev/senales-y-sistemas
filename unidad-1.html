1.1Señal, sistema y clasificación

Definición

Una señal es una función de una o más variables independientes que porta información sobre el comportamiento o la naturaleza de un fenómeno. Un sistema es una entidad que transforma una señal de entrada en una señal de salida: y = T{x}.

La primera distinción es la del dominio de la variable independiente. En tiempo continuo se escribe x(t) con t ∈ ℝ; en tiempo discreto, x[n] con n ∈ ℤ, donde n no es un tiempo sino un índice de muestra. Los corchetes no son un capricho tipográfico: señalan que entre dos muestras consecutivas la señal sencillamente no está definida.

Simetría: descomposición par–impar

Toda señal admite una descomposición única en su parte par y su parte impar, útil para simplificar integrales y convoluciones:

\[ x_p(t) = \tfrac{1}{2}\big[\,x(t) + x(-t)\,\big] \qquad x_i(t) = \tfrac{1}{2}\big[\,x(t) - x(-t)\,\big] \] x(t) = xp(t) + xi(t) para toda señal real o compleja.

Conviene recordar dos consecuencias: el producto de dos señales pares es par, el de dos impares también es par, y el de una par por una impar es impar. Además, la integral de una señal impar sobre un intervalo simétrico es cero, lo que ahorra cálculos completos.

Periodicidad: continua frente a discreta

Una senoidal continua siempre es periódica; una discreta no. La exponencial compleja ejΩn es periódica solo si Ω/2π es un número racional. Por eso el taller 1 pide calcular por separado el periodo de x(t) = 2 cos(5πt/3) y el de x[n] = 2 cos(5πn/3):

\[ \begin{aligned} \text{Continua:}\quad & \omega_0 = \frac{5\pi}{3} \;\Rightarrow\; T_0 = \frac{2\pi}{\omega_0} = 1.2\ \text{s} \\ \text{Discreta:}\quad & \Omega_0 = \frac{5\pi}{3} \;\Rightarrow\; N = m\,\frac{2\pi}{\Omega_0} = m\,\frac{6}{5} \;\Rightarrow\; m = 5,\;\; N = 6 \ \text{muestras} \end{aligned} \] En tiempo discreto el periodo debe ser entero: se busca el menor entero m que lo consiga.

Ejemplo resuelto 1.1 — clasificación completa

Clasifique x[n] = 3 cos(πn/10) − 2 en cuanto a simetría y periodicidad (taller 1, punto 1b).

  1. Simetría. x[−n] = 3 cos(−πn/10) − 2 = 3 cos(πn/10) − 2 = x[n]. El coseno es par y la constante también, así que la señal es par.
  2. Periodicidad. Ω₀ = π/10, de modo que 2π/Ω₀ = 20, un entero. La señal es periódica con N = 20 muestras.
  3. Potencia. Al no decaer, tiene energía infinita pero potencia media finita: es una señal de potencia.

x[n] es par, periódica con N = 20, señal de potencia. El término −2 desplaza el nivel medio pero no altera ni la simetría ni el periodo.

1.2Energía y potencia

Clasificar una señal por su contenido energético decide qué herramientas se pueden aplicar después: las señales de energía admiten transformada de Fourier ordinaria, las de potencia se describen mejor por series o densidades espectrales.

\[ \begin{aligned} E &= \int_{-\infty}^{\infty} |x(t)|^{2}\,dt &\qquad P &= \lim_{T\to\infty}\frac{1}{2T}\int_{-T}^{T} |x(t)|^{2}\,dt \\ E &= \sum_{n=-\infty}^{\infty} |x[n]|^{2} &\qquad P &= \lim_{N\to\infty}\frac{1}{2N+1}\sum_{n=-N}^{N} |x[n]|^{2} \end{aligned} \] Si E es finita, P = 0. Si P es finita y no nula, E es infinita. Una señal puede no ser ni de energía ni de potencia, como x(t) = t·u(t).

Para una señal periódica basta integrar sobre un periodo: P = (1/T₀)∫T₀|x(t)|²dt. Así, una senoidal de amplitud A tiene potencia A²/2, y de ahí sale el valor eficaz A/√2 que se usa en circuitos.

Atajo útil. Toda señal de duración finita y amplitud acotada es de energía. Toda señal periódica distinta de cero es de potencia. Con esas dos reglas se resuelve la mayoría de los ejercicios sin integrar.

1.3Señales básicas

Casi cualquier señal del curso se construye combinando cinco elementos. Conviene memorizar tanto su expresión como su gráfica.

Señales elementales en tiempo continuo y discreto
SeñalTiempo continuoTiempo discreto
Impulso\( \delta (t), \int \delta (t)dt = 1 \)\( \delta [n] = 1 \ \text\{si\} \ n = 0 \)
Escalón\( u(t) = 1 \ \text\{si\} \ t \ge 0 \)\( u[n] = 1 \ \text\{si\} \ n \ge 0 \)
Rampa\( r(t) = t \cdot u(t) \)\( r[n] = n \cdot u[n] \)
Exponencial\( x(t) = C e^\{at\} \)\( x[n] = C a^{n} \)
Senoidal\( A \cos(\omega _{0}t + \varphi ) \)\( A \cos(\Omega _{0}n + \varphi ) \)
Pulso rectangular\( \Pi (t/\tau ) = u(t+\tau /2) - u(t-\tau /2) \)\( u[n] - u[n - N] \)

Las tres primeras están encadenadas por derivación e integración, y el impulso tiene una propiedad que se usará durante todo el curso: la propiedad de muestreo.

\[ \int_{-\infty}^{\infty} x(t)\,\delta(t - t_0)\,dt = x(t_0) \qquad\qquad x[n] = \sum_{k} x[k]\,\delta[n - k] \] Toda señal discreta es una suma ponderada de impulsos desplazados. De aquí nace la convolución de la unidad 2.

Otras propiedades del impulso que aparecen en los talleres: x(t)δ(t − t₀) = x(t₀)δ(t − t₀), δ(at) = δ(t)/|a| y δ(−t) = δ(t). El impulso continuo no es una función ordinaria sino una distribución: solo tiene sentido dentro de una integral.

Construcción de señales por tramos

Un pulso, una escalera o una rampa truncada se escriben como suma de escalones desplazados. Esta forma es la más cómoda para transformar después con Laplace:

\[ x(t) = 2\big[u(t) - u(t-1)\big] + (3 - t)\big[u(t-1) - u(t-3)\big] \] Cada corchete «enciende» un tramo y lo «apaga» en el instante siguiente.
senales_basicas.m
%% Señales básicas en tiempo continuo y discreto
t = -2:0.001:5;            % paso fino: aparenta continuidad
n = -2:5;                  % índices enteros

u  = @(t) double(t >= 0);  % escalón unitario como función anónima
r  = @(t) t.*u(t);         % rampa

figure('Name','Señales básicas')
subplot(2,2,1), plot(t, u(t), 'LineWidth', 1.5), ylim([-0.2 1.2])
title('Escalón u(t)'), xlabel('t [s]'), grid on

subplot(2,2,2), plot(t, r(t), 'LineWidth', 1.5)
title('Rampa r(t) = t·u(t)'), xlabel('t [s]'), grid on

subplot(2,2,3), stem(n, double(n == 0), 'filled')
title('Impulso \delta[n]'), xlabel('n'), grid on

subplot(2,2,4), plot(t, 2*exp(-0.6*t).*u(t), 'LineWidth', 1.5)
title('Exponencial 2e^{-0.6t}u(t)'), xlabel('t [s]'), grid on

%% Señal definida por tramos con escalones
x = 2*(u(t) - u(t-1)) + (3 - t).*(u(t-1) - u(t-3));
figure, plot(t, x, 'LineWidth', 1.6), grid on
xlabel('t [s]'), ylabel('x(t)'), title('Señal construida por tramos')

1.4Exponencial compleja y fasores

La exponencial compleja es la señal más importante del curso: es la única que atraviesa un sistema LTI sin cambiar de forma, solo escalada por un número complejo. Esa propiedad es la razón de ser de Laplace, de Fourier y de la Transformada Z.

\[ e^{j\omega_0 t} = \cos(\omega_0 t) + j\,\operatorname{sen}(\omega_0 t) \quad\Longrightarrow\quad \cos(\omega_0 t) = \frac{e^{j\omega_0 t} + e^{-j\omega_0 t}}{2} \qquad \operatorname{sen}(\omega_0 t) = \frac{e^{j\omega_0 t} - e^{-j\omega_0 t}}{2j} \] Relación de Euler. Convierte productos de senoidales en sumas de exponenciales, mucho más fáciles de integrar.

La forma general x(t) = C est con C = |C|ejθ y s = σ + jω₀ describe de una sola vez cuatro comportamientos, según dónde caiga s en el plano complejo:

Comportamiento de la exponencial compleja según s
\( \sigma \)\( \omega _{0} \)Comportamiento
\( \sigma = 0 \)\( \omega _{0} = 0 \)Constante
\( \sigma = 0 \)\( \omega _{0} \ne 0 \)Oscilación sostenida de amplitud constante
\( \sigma < 0 \)\( \omega _{0} \ne 0 \)Oscilación amortiguada (envolvente eσt decreciente)
\( \sigma > 0 \)\( \omega _{0} \ne 0 \)Oscilación creciente sin límite

Esa tabla es, anticipadamente, el mapa de polos del plano s de la unidad 3: cada polo aporta a la respuesta un término de esta familia.

Diferencia clave en tiempo discreto

En ejΩn las frecuencias Ω y Ω + 2π producen exactamente la misma secuencia. Por eso el rango de frecuencias discretas útiles se limita a un intervalo de longitud 2π, normalmente −π < Ω ≤ π, y la frecuencia «más rápida» posible es Ω = π, que alterna +1, −1, +1…

1.5Operaciones sobre la variable independiente

Tres operaciones, un solo orden correcto. Dada x(t), la señal transformada x(at − t₀) se obtiene siempre en este orden:

  1. Desplazamiento en t₀: x(t) → x(t − t₀). Hacia la derecha si t₀ > 0.
  2. Escalamiento por |a|: compresión si |a| > 1, expansión si |a| < 1.
  3. Reflexión si a < 0: se espeja respecto al eje vertical.

Si se invierte el orden entre desplazamiento y escalamiento el resultado es otro: x(a(t − t₀)) ≠ x(at − t₀). La regla segura es factorizar el argumento y leerlo como «primero desplazo t₀, luego escalo por a».

Ejemplo resuelto 1.2 — punto de control por coordenadas

Si x(t) vale 3 en t = 2, ¿en qué instante vale 3 la señal w(t) = x(−2t + 4)?

  1. Se iguala el argumento al valor conocido: −2t + 4 = 2.
  2. Se despeja: t = 1.

w(1) = 3. Rastrear dos o tres puntos característicos —inicio, quiebre y final del soporte— es más rápido y más seguro que redibujar la señal completa.

Caso discreto

En x[an] el escalamiento solo está definido para valores enteros del argumento. Si a > 1 se pierden muestras (diezmado) y la operación no es invertible; si a = 1/M hay que interpolar. Por eso el taller 2 insiste en evaluar muestra a muestra.

1.6Derivación e integración de señales

Derivar una señal continua resalta sus cambios: un salto de amplitud A en t₀ produce un impulso A δ(t − t₀). Integrar hace lo contrario, acumula área y suaviza.

\[ \frac{d\,u(t)}{dt} = \delta(t) \qquad \int_{-\infty}^{t} \delta(\tau)\,d\tau = u(t) \qquad \int_{-\infty}^{t} u(\tau)\,d\tau = r(t) \]

Para una señal definida a tramos —como la del taller 3— el procedimiento es sistemático:

  1. Derivar cada tramo por separado (la pendiente de cada recta).
  2. Añadir un impulso por cada discontinuidad de salto, con área igual al tamaño del salto.
  3. Al integrar, verificar la continuidad de la señal resultante en las fronteras de cada tramo: la integral de una señal acotada nunca salta.

Ejemplo resuelto 1.3 — integración de un semiciclo de seno

Sea x(t) = sen(t) para 0 ≤ t ≤ 2π y cero en otro caso. Obtenga y(t) = ∫−∞t x(τ)dτ (taller 3, punto 2).

  1. Para t < 0 no hay área acumulada: y(t) = 0.
  2. Para 0 ≤ t ≤ 2π: y(t) = ∫₀ᵗ sen(τ)dτ = 1 − cos(t). Crece hasta 2 en t = π y vuelve a bajar.
  3. Para t > 2π el área total acumulada es 1 − cos(2π) = 0, así que y(t) = 0.

y(t) = (1 − cos t)·[u(t) − u(t − 2π)]. La señal integrada es continua en t = 0 y en t = 2π, como debe ser.

En tiempo discreto los operadores equivalentes son la primera diferencia x[n] − x[n − 1] y la suma acumulada Σk ≤ n x[k], que en MATLAB son diff y cumsum.

derivada_integral.m
%% Derivada e integral numéricas de una señal por tramos
dt = 1e-3;  t = -1:dt:8;
x  = sin(t).*(t >= 0 & t <= 2*pi);      % semiciclo de seno

dx = [0 diff(x)/dt];                     % derivada aproximada
ix = cumsum(x)*dt;                       % integral acumulada

figure
subplot(3,1,1), plot(t, x,  'LineWidth', 1.5), grid on, ylabel('x(t)')
subplot(3,1,2), plot(t, dx, 'LineWidth', 1.2), grid on, ylabel('dx/dt')
subplot(3,1,3), plot(t, ix, 'LineWidth', 1.5), grid on, ylabel('\int x'), xlabel('t [s]')

%% Comprobación simbólica
syms tau T
y = int(sin(tau), tau, 0, T)             % devuelve 1 - cos(T)

1.7Muestreo y aliasing

El taller 1 cierra con una pregunta que parece inocente: ¿se puede reconstruir x(t) = 2cos(2πt) a partir de x[n] = 2cos(2πn)? La respuesta es no, y el motivo es el teorema de muestreo.

\[ f_s > 2 f_{\max} \quad \text{(criterio de Nyquist)} \qquad\qquad \Omega = \omega T = \frac{\omega}{f_s} \] Al muestrear con T = 1 s una señal de 1 Hz se obtiene Ω = 2π, indistinguible de Ω = 0: todas las muestras valen lo mismo.

Cuando fs no es suficiente aparece el aliasing: una componente de alta frecuencia se disfraza de una de baja frecuencia y la reconstrucción falla. La estrategia que pide el taller para que la secuencia discreta se parezca a la continua es aumentar la frecuencia de muestreo, es decir, reducir T.

Relación con la unidad 4. El cambio de variable z = esT que abre la Transformada Z es exactamente esta operación de muestreo vista en el plano complejo: comprime todo el plano s en el interior y el exterior del círculo unitario, con periodicidad 2π en la frecuencia.
muestreo_aliasing.m
%% Aliasing: la misma señal muestreada a dos frecuencias
f  = 1;                       % señal de 1 Hz
t  = 0:1e-4:5;
x  = 2*cos(2*pi*f*t);

fs1 = 1;    n1 = 0:1/fs1:5;   % muestreo insuficiente (fs = f)
fs2 = 20;   n2 = 0:1/fs2:5;   % muestreo holgado  (fs = 20f)

figure
plot(t, x, 'LineWidth', 1.2), hold on
stem(n1, 2*cos(2*pi*f*n1), 'filled')
stem(n2, 2*cos(2*pi*f*n2), 'Marker', 'x')
hold off, grid on
legend('x(t)', 'fs = 1 Hz (aliasing)', 'fs = 20 Hz')
xlabel('t [s]'), title('Criterio de Nyquist: fs > 2·f_{max}')

1.8Propiedades de los sistemas

Estas seis propiedades deciden qué herramientas se pueden usar más adelante. Solo un sistema lineal e invariante en el tiempo admite el tratamiento por convolución, Laplace o Z.

Propiedades de los sistemas
PropiedadCondiciónEjemplo que la cumple
MemoriaLa salida en t depende de valores de la entrada distintos de x(t).\( y[n] = x[n] + x[n-1] \)
Causalidady(t₀) depende solo de x(t) con t ≤ t₀.\( y[n] = x[n] - x[n-2] \)
Estabilidad BIBOToda entrada acotada produce salida acotada.\( y(t) = \cos(x(t)) \)
Invarianza en el tiempoSi x(t) → y(t), entonces x(t−t₀) → y(t−t₀).\( y(t) = 3x(t) + 1 \)
Linealidada x₁ + b x₂ → a y₁ + b y₂.\( y(t) = t \cdot x(t) \)
InvertibilidadEntradas distintas producen salidas distintas.\( y(t) = 2x(t) \)

Ejemplo resuelto 1.4 — dos sistemas parecidos, propiedades opuestas

Analice y₁(t) = t·x(t) y y₂(t) = 3x(t) + 1.

Sistema 1: y₁(t) = t·x(t)

  1. Lineal: T{ax₁ + bx₂} = t(ax₁ + bx₂) = a·tx₁ + b·tx₂. Sí cumple.
  2. Invariante: la respuesta a x(t − t₀) es t·x(t − t₀), pero la salida desplazada es (t − t₀)·x(t − t₀). No coinciden: variante en el tiempo.
  3. Estable: con x acotada, t·x(t) crece sin límite. No es BIBO estable.

Sistema 2: y₂(t) = 3x(t) + 1

  1. Lineal: con x = 0 la salida es 1, no 0. No es lineal (es afín).
  2. Invariante: sí, ningún coeficiente depende de t.
  3. Estable y sin memoria: sí en ambos casos.

Ninguno de los dos es LTI: al primero le falla la invarianza y al segundo la linealidad. La prueba de linealidad más rápida es verificar que entrada nula produzca salida nula.

1.9Ecuaciones diferenciales y de diferencias

Los sistemas LTI de parámetros concentrados se describen con ecuaciones diferenciales lineales de coeficientes constantes, y sus equivalentes discretos con ecuaciones de diferencias:

\[ \begin{aligned} \sum_{k=0}^{N} a_k\,\frac{d^{k} y(t)}{dt^{k}} &= \sum_{k=0}^{M} b_k\,\frac{d^{k} x(t)}{dt^{k}} \\ \sum_{k=0}^{N} a_k\,y[n-k] &= \sum_{k=0}^{M} b_k\,x[n-k] \end{aligned} \] N es el orden del sistema. La solución total es la suma de la respuesta natural (homogénea) y la respuesta forzada (particular).

Un circuito RLC serie conduce a una ecuación de segundo orden cuya solución analítica se vuelve laboriosa: hay que proponer una forma, imponer condiciones iniciales y resolver un sistema de ecuaciones. La unidad 3 mostrará cómo la Transformada de Laplace convierte esa ecuación diferencial en una ecuación algebraica y las condiciones iniciales en simples términos adicionales.

De la ley física a la ecuación

Para el RLC serie con fuente v(t) y corriente i(t): v(t) = L·di/dt + R·i + (1/C)∫i dt. Derivando una vez para eliminar la integral se obtiene L·i″ + R·i′ + i/C = v′(t), una ecuación de segundo orden en la corriente.

%% Taller 1: graficar, clasificar y medir
t = -5:0.001:5;

%% Simetría: comparar x(t) con x(-t)
par   = (x + fliplr(x))/2;
impar = (x - fliplr(x))/2;
if max(abs(impar)) < 1e-9
    disp('La señal es PAR')
elseif max(abs(par)) < 1e-9
    disp('La señal es IMPAR')
else
    disp('No es par ni impar')
end

%% Periodo fundamental de la señal discreta
Omega = 5*pi/3;
m = 1;
while mod(m*2*pi/Omega, 1) > 1e-9
    m = m + 1;                % se busca el menor m que hace N entero
end
N = m*2*pi/Omega;
fprintf('Periodo discreto: N = %d muestras (con m = %d)\n', N, m)

%% Energía y potencia
dt = t(2) - t(1);
E  = sum(abs(x).^2)*dt;                  % energía en la ventana
P  = E/(t(end) - t(1));                  % potencia media
fprintf('Energía = %.3f | Potencia media = %.3f\n', E, P)

El resultado de la potencia media debe acercarse a A²/2 = 2 para una senoidal de amplitud 2, siempre que la ventana contenga un número entero de periodos. Es una buena comprobación de que el código está bien escrito.
