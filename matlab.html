M.1Entorno y convenios

Los guiones de esta página usan tres toolboxes. Se puede comprobar cuáles están instaladas con el comando ver:

Convenios que se repiten en todos los guiones

  • Tiempo continuo: vector con paso fino (t = a:1e-3:b) y gráficas con plot.
  • Tiempo discreto: vector de enteros (n = a:b) y gráficas con stem.
  • Escalón: función anónima u = @(t) double(t >= 0), más segura que heaviside porque en t = 0 devuelve 1 y no 0.5.
  • Operaciones elemento a elemento: siempre con punto: .*, ./, .^.
  • Ejes: rotular con xlabel, ylabel, title y activar grid on. En el informe, una gráfica sin ejes rotulados no puntúa.

M.2Graficar y clasificar señales

Relacionado con la unidad 1 y el taller 1. Este guion automatiza las tres preguntas del taller: gráfica, simetría y periodicidad.

clasificar_senal.m
%% Función que clasifica una señal discreta y la grafica
function info = clasificar_senal(x, n, nombre)
% x: vector de muestras | n: eje de índices (simétrico) | nombre: texto

    xr = fliplr(x);                        % x[-n] si n es simétrico
    info.par   = max(abs(x - xr)) < 1e-9;
    info.impar = max(abs(x + xr)) < 1e-9;

    % Búsqueda del periodo: se ensayan desplazamientos sucesivos
    info.N = NaN;
    for N = 1:floor(numel(x)/2)
        if max(abs(x(1:end-N) - x(1+N:end))) < 1e-9
            info.N = N;  break
        end
    end
    info.periodica = ~isnan(info.N);

    % Energía y potencia
    info.energia  = sum(abs(x).^2);
    info.potencia = info.energia/numel(x);

    stem(n, x, 'filled'), grid on
    xlabel('n'), ylabel(nombre)
    if info.par,   simetria = 'par';
    elseif info.impar, simetria = 'impar';
    else,          simetria = 'ni par ni impar';
    end
    if info.periodica
        title(sprintf('%s: %s, periódica con N = %d', nombre, simetria, info.N))
    else
        title(sprintf('%s: %s, no periódica', nombre, simetria))
    end
end

% n = -20:20;
% clasificar_senal(sin(pi*n/10 + 2),      n, 'x_1[n]')
% clasificar_senal(3*cos(pi*n/10) - 2,    n, 'x_2[n]')
% clasificar_senal(-5*n.^2 - 2*n + 1,     n, 'x_6[n]')

M.4Convolución

Relacionado con la unidad 2 y los talleres 4 y 5. El error más común no está en conv sino en el eje de índices del resultado.

convolucion_con_ejes.m
%% Función de convolución que devuelve también el eje correcto
function [y, ny] = convolucion_con_ejes(x, nx, h, nh)
    y  = conv(x, h);
    ny = (nx(1) + nh(1)) : (nx(end) + nh(end));

    % Verificaciones automáticas
    assert(numel(y) == numel(ny), 'El eje no coincide con la longitud')
    assert(abs(sum(y) - sum(x)*sum(h)) < 1e-9, 'Falla la suma de comprobación')
end

%% Uso con el punto 2 del taller 4
% [y, ny] = convolucion_con_ejes([-2 -1 1], -2:0, [1 1 -2], -1:1);
% stem(ny, y, 'filled'), grid on
% resultado esperado: y = [-2 -3 4 3 -2] para n = -3:1
convolucion_exponencial.m
%% Convolución de un pulso con una exponencial: numérica vs. analítica
dt = 1e-4;  t = -2:dt:12;
u  = @(t) double(t >= 0);

x = u(t) - u(t-2);
h = 2*exp(-t).*u(t);

y_num = conv(x, h)*dt;
ty    = t(1)*2 : dt : t(end)*2;
y_num = y_num(1:numel(ty));

% Solución analítica por tramos (ver ejemplo 2.2 de la unidad 2)
y_ana = 2*(1 - exp(-t)).*(t>=0 & t<2) + 2*(exp(2)-1)*exp(-t).*(t>=2);

figure
plot(ty, y_num, 'LineWidth', 2), hold on
plot(t, y_ana, '--', 'LineWidth', 1.4), hold off
grid on, xlim([-1 10]), legend('numérica', 'analítica')
xlabel('t [s]'), ylabel('y(t)'), title('Contraste numérico-analítico')

% Error máximo en la zona común
y_int = interp1(ty, y_num, t);
fprintf('Error máximo: %.2e\n', max(abs(y_int - y_ana), [], 'omitnan'))

M.5Diagramas de bloques

Relacionado con la unidad 2. MATLAB tiene una función por cada regla de reducción, así que el guion sirve para comprobar el resultado hecho a mano.

verificar_reduccion.m
%% Comprobar a mano vs. MATLAB una reducción de bloques
s  = tf('s');
G1 = 4/(s + 2);
G2 = 1/s;
H  = 0.5;

% Reducción paso a paso
G_serie = series(G1, G2);
G_lazo  = feedback(G_serie, H);        % negativa por defecto
G_total = parallel(G_lazo, tf(2, 1));

% Resultado esperado calculado a mano
G_mano = (2*s^2 + 4*s + 8)/(s^2 + 2*s + 2);

% Comparación: la diferencia debe ser prácticamente cero
dif = minreal(G_total - G_mano);
fprintf('Norma de la diferencia: %.2e\n', norm(dif, inf))

% Realimentación positiva: feedback(G, H, +1)
G_pos = feedback(G_serie, H, +1);
fprintf('Polos con realimentación positiva: %s\n', mat2str(pole(G_pos), 3))

M.6Transformada de Laplace

Relacionado con la unidad 3 y el taller 7. Conviene resolver siempre por los dos caminos: simbólico para el informe, numérico para las gráficas.

taller07_laplace.m
%% Taller 7 completo: ecuaciones diferenciales e inversión
clear; clc
syms t s y(t)

%% 1a) y'' + 12y' + 32y = 32u(t)
Dy   = diff(y, t);
edo1 = diff(y, t, 2) + 12*Dy + 32*y == 32*heaviside(t);
sol1 = simplify(dsolve(edo1, y(0) == 0, Dy(0) == 0))
%  resultado: 1 - 2*exp(-4*t) + exp(-8*t)

%% 1b) y'' + 3y' + 2y = 5r(t), con r(t) = t*u(t)
edo2 = diff(y, t, 2) + 3*Dy + 2*y == 5*t*heaviside(t);
sol2 = simplify(dsolve(edo2, y(0) == 0, Dy(0) == 0))

%% 2a) Inversa de G1(s) = (s+2)/(s^3+7s^2+19s+13)
G1 = (s + 2)/(s^3 + 7*s^2 + 19*s + 13);
factor(s^3 + 7*s^2 + 19*s + 13)        % (s+1)(s^2+6s+13)
g1 = simplify(ilaplace(G1))

%% 2b) Inversa de G2(s) = (s-2)/(s^4+2s^3+5s^2+8s+4)
G2 = (s - 2)/(s^4 + 2*s^3 + 5*s^2 + 8*s + 4);
g2 = simplify(ilaplace(G2))

%% Gráficas de las respuestas obtenidas
figure
fplot(sol1, [0 2], 'LineWidth', 1.6), grid on
xlabel('t [s]'), ylabel('y(t)'), title('Respuesta al escalón, punto 1a')
fracciones_parciales.m
%% Fracciones parciales: residuos, polos y término directo
num = [1 2];
den = [1 7 19 13];

[r, p, k] = residue(num, den);

for m = 1:numel(p)
    if imag(p(m)) == 0
        fprintf('Polo real     %+.4f  ->  residuo %+.4f\n', p(m), r(m));
    else
        fprintf('Polo complejo %+.4f%+.4fj  ->  residuo %+.4f%+.4fj\n', ...
                real(p(m)), imag(p(m)), real(r(m)), imag(r(m)));
    end
end

% Reconstrucción de la respuesta temporal a partir de los residuos
t = 0:1e-3:6;
y = zeros(size(t));
for m = 1:numel(p)
    y = y + real(r(m)*exp(p(m)*t));
end
plot(t, y, 'LineWidth', 1.6), grid on
xlabel('t [s]'), title('Respuesta reconstruida desde los residuos')

routh_hurwitz.m
%% Arreglo de Routh-Hurwitz para un polinomio característico
function R = routh_hurwitz(den)
    n = numel(den);
    R = zeros(n, ceil(n/2));
    R(1, 1:numel(den(1:2:end))) = den(1:2:end);
    R(2, 1:numel(den(2:2:end))) = den(2:2:end);

    for i = 3:n
        for j = 1:size(R,2)-1
            a = R(i-2, 1);  b = R(i-1, 1);
            if b == 0, b = eps; end            % evita la división por cero
            R(i, j) = (b*R(i-2, j+1) - a*R(i-1, j+1))/b;
        end
    end

    cambios = sum(diff(sign(R(:,1)) ~= 0) ~= 0);
    fprintf('Primera columna: %s\n', mat2str(R(:,1)', 4))
    if all(R(:,1) > 0)
        disp('ESTABLE: sin cambios de signo en la primera columna')
    else
        fprintf('INESTABLE: %d raíz/raíces en el semiplano derecho\n', cambios)
    end
end

% Uso:  routh_hurwitz([1 7 19 13])  ->  estable
%       routh_hurwitz([1 1 2 24])   ->  inestable

M.8Transformada Z y filtros digitales

Relacionado con la unidad 4. Además de invertir transformadas, MATLAB permite comprobar en segundos si un polo cae dentro del círculo unitario.

estabilidad_discreta.m
%% Barrido del polo: efecto sobre h[n] y sobre la estabilidad
polos = [0.5 0.85 1.0 1.05 -0.85];
N     = 0:25;

figure
for k = 1:numel(polos)
    a = polos(k);
    h = a.^N;                        % h[n] = a^n u[n]

    subplot(numel(polos), 1, k)
    stem(N, h, 'filled'), grid on
    ylabel(sprintf('a = %.2f', a))

    if abs(a) < 1
        veredicto = sprintf('estable, suma |h| = %.2f', 1/(1-abs(a)));
    else
        veredicto = 'inestable';
    end
    title(veredicto)
end
xlabel('n')
