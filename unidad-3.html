Unidad 3

Transformada de Laplace

Una ecuación diferencial con condiciones iniciales se convierte en una ecuación algebraica; la convolución se convierte en un producto; y la estabilidad, en una pregunta sobre la posición de unos puntos en el plano complejo.

3.1Definición y región de convergencia

\[ \underbrace{X(s) = \int_{-\infty}^{\infty} x(t)\,e^{-st}\,dt}_{\text{bilateral}} \qquad\qquad \underbrace{X(s) = \int_{0^{-}}^{\infty} x(t)\,e^{-st}\,dt}_{\text{unilateral}} \] s = σ + jω. La versión unilateral es la que se usa para resolver ecuaciones diferenciales con condiciones iniciales.

La transformada solo existe donde la integral converge. Ese conjunto de valores de s es la región de convergencia (ROC), y no es un detalle técnico: la misma expresión algebraica X(s) puede corresponder a dos señales distintas según su ROC.

Ejemplo resuelto 3.1 — la misma X(s), dos señales

Calcule la transformada de x₁(t) = e−atu(t) y de x₂(t) = −e−atu(−t).

  1. Señal causal. X₁(s) = ∫₀∞e−(s+a)tdt = 1/(s + a), convergente si Re{s} > −a.
  2. Señal anticausal. X₂(s) = −∫−∞0e−(s+a)tdt = 1/(s + a), convergente si Re{s} < −a.

Misma expresión, ROC opuestas. Sin declarar la ROC, la transformada inversa es ambigua.

Reglas de la ROC

  • Nunca contiene polos.
  • Señal causal → semiplano derecho, a la derecha del polo más a la derecha.
  • Señal anticausal → semiplano izquierdo.
  • Señal bilateral de duración infinita → franja vertical entre dos polos.
  • Señal de duración finita → todo el plano s (salvo, quizá, s = 0 o s = ∞).
  • Si la ROC incluye el eje jω, existe la transformada de Fourier.

Los teoremas de valor inicial y final permiten conocer los extremos de la respuesta sin invertir la transformada:

3.4Transformada inversa por fracciones parciales

Con X(s) racional y propia, la inversión se reduce a descomponer en fracciones simples y leer la tabla. Si el grado del numerador iguala o supera al del denominador, primero se hace división polinómica: el cociente aporta impulsos y sus derivadas.

Caso 1 · polos reales distintos

\[ X(s) = \frac{N(s)}{(s + p_1)(s + p_2)} = \frac{A_1}{s + p_1} + \frac{A_2}{s + p_2} \] Ak = [(s + pk) X(s)] evaluado en s = −pk. Cada término aporta Ak e−pkt.

Caso 2 · polos repetidos

\[ X(s) = \frac{A_1}{s + p} + \frac{A_2}{(s + p)^{2}} \quad\longrightarrow\quad \big(A_1 + A_2\,t\big)e^{-pt} \] A₂ se obtiene evaluando (s+p)²X(s) en s = −p; A₁, derivando esa misma expresión respecto a s antes de evaluar.

Caso 3 · polos complejos conjugados

Conviene no separarlos: se completa el cuadrado en el denominador y se identifica un par seno–coseno amortiguado. Así, s² + 6s + 13 = (s + 3)² + 2² conduce a términos e−3tcos(2t) y e−3tsen(2t).

Ejemplo resuelto 3.2 — inversión con polo real y par complejo

G₁(s) = (s + 2)/(s³ + 7s² + 19s + 13), del taller 7.

  1. Factorizar el denominador. s = −1 lo anula, así que s³ + 7s² + 19s + 13 = (s + 1)(s² + 6s + 13).
  2. Completar el cuadrado. s² + 6s + 13 = (s + 3)² + 2², es decir, polos en s = −3 ± j2.
  3. Descomponer.
    \[ G_1(s) = \frac{A}{s + 1} + \frac{Bs + C}{(s + 3)^{2} + 4} \]
  4. Hallar A. A = (s + 2)/(s² + 6s + 13) evaluado en s = −1: A = 1/8.
  5. Hallar B y C igualando coeficientes: B = −1/8 y C = 3/8.
  6. Reagrupar el numerador en términos de (s + 3): −⅛(s + 3) + ¾, para leer la tabla directamente.

g₁(t) = ⅛e−t − ⅛e−3tcos(2t) + ⅜e−3tsen(2t),   t > 0

Comprobación rápida. Evalúe el resultado en t = 0 y compárelo con el teorema del valor inicial: líms→∞ sG₁(s) = 0 y, en efecto, ⅛ − ⅛ = 0.

3.5Solución de ecuaciones diferenciales

El procedimiento es siempre el mismo, y las condiciones iniciales entran solas por la propiedad de la derivada:

  1. Transformar término a término, arrastrando y(0⁻) y y′(0⁻).
  2. Despejar Y(s) algebraicamente.
  3. Separar la respuesta a entrada cero (condiciones iniciales) de la respuesta a estado cero (entrada).
  4. Invertir por fracciones parciales.
  5. Verificar con los teoremas de valor inicial y final.

Ejemplo resuelto 3.3 — sistema de segundo orden ante escalón

y″ + 12y′ + 32y = 32u(t), con y(0) = y′(0) = 0 (taller 7, punto 1a).

  1. Transformar. (s² + 12s + 32)Y(s) = 32/s.
  2. Despejar y factorizar. Y(s) = 32 / [s(s + 4)(s + 8)].
  3. Fracciones parciales. A = 32/(4·8) = 1; B = 32/[(−4)(4)] = −2; C = 32/[(−8)(−4)] = 1.
  4. Invertir. y(t) = 1 − 2e−4t + e−8t.
  5. Verificar. Valor final: líms→0 sY(s) = 1, que coincide con el régimen permanente. Valor inicial: 1 − 2 + 1 = 0. ✔

y(t) = 1 − 2e−4t + e−8t,   t > 0. Sistema sobreamortiguado: dos polos reales, sin oscilación.

Entrada rampa. El punto 1b del mismo taller usa r(t), cuya transformada es 1/s². El procedimiento no cambia; solo aparece un polo doble en el origen, que produce un término lineal en la respuesta permanente.

3.6Función de transferencia y estabilidad

Función de transferencia

H(s) = Y(s)/X(s) con condiciones iniciales nulas. Es la Transformada de Laplace de la respuesta al impulso: los polos son las raíces del denominador y determinan la forma de la respuesta natural; los ceros, las del numerador, modulan su amplitud.

La correspondencia entre la posición de un polo y el comportamiento temporal es directa: parte real negativa ⇒ decaimiento; parte imaginaria distinta de cero ⇒ oscilación; parte real positiva ⇒ crecimiento sin límite. De ahí el criterio: un sistema causal es estable si y solo si todos sus polos tienen parte real negativa.

3.8Criterio de Routh-Hurwitz

Cuando el denominador es de grado alto, no hace falta calcular las raíces para decidir la estabilidad: basta contar cambios de signo en la primera columna del arreglo de Routh.

\[ D(s) = a_0 s^{n} + a_1 s^{\,n-1} + \dots + a_{n-1} s + a_n \] Condición necesaria: todos los coeficientes presentes y del mismo signo. Si falta uno o cambia de signo, el sistema ya es inestable.

Ejemplo resuelto 3.4 — arreglo de Routh

D(s) = s³ + 7s² + 19s + 13, el denominador del taller 7.

  1. Primera fila (s³): 1, 19. Segunda fila (s²): 7, 13.
  2. Fila s¹: (7·19 − 1·13)/7 = 120/7 ≈ 17.14.
  3. Fila s⁰: 13.
  4. Primera columna: 1, 7, 17.14, 13. Todos positivos, sin cambios de signo.

Cero raíces en el semiplano derecho: el sistema es estable. Coincide con las raíces halladas antes: −1 y −3 ± j2.

3.9Circuitos en el dominio s

No hace falta plantear la ecuación diferencial para obtener H(s): con condiciones iniciales nulas, cada elemento pasivo tiene una impedancia en s y el circuito se analiza con divisores de tensión y las leyes de Kirchhoff, exactamente igual que en corriente continua.

\[ Z_R(s) = R \qquad\qquad Z_L(s) = sL \qquad\qquad Z_C(s) = \frac{1}{sC} \] Con condiciones iniciales no nulas se añade una fuente: Li(0⁻) en serie con la inductancia y vC(0⁻)/s en serie con el condensador.

Filtros elementales

RL, salida en R\( R/(Ls + R) \)Pasa-bajas, ωc = R/L
RLC serie, salida en R\( (R/L)s / (s^{2} + (R/L)s + 1/LC) \)Pasa-banda
RLC serie, salida en C\( (1/LC) / (s^{2} + (R/L)s + 1/LC) \)Pasa-bajas de 2.º orden

Ejemplo resuelto 3.5 — el RC pasa-bajas, verificado

  1. Divisor de tensión en s: H(s) = ZC/(ZR + ZC) = (1/sC)/(R + 1/sC) = 1/(RCs + 1).
  2. Polo: s = −1/RC, en el semiplano izquierdo: estable para cualquier R, C positivos.
  3. Comportamiento en frecuencia: |H(j0)| = 1 y |H(jω)| → 0 cuando ω → ∞. En ω = 1/RC la ganancia cae a 1/√2, es decir, −3 dB.
  4. Respuesta al escalón: Y(s) = 1/[s(RCs + 1)] ⟹ y(t) = 1 − e−t/RC, la carga clásica del condensador.

El circuito sí es pasa-bajas: el análisis lo demuestra en tres dominios —polos, frecuencia y tiempo— en lugar de suponerlo por su nombre.

Ese es exactamente el ejercicio de la práctica final: tomar el esquemático de un filtro, obtener su ecuación diferencial y su función de transferencia, invertir para hallar la respuesta temporal y contrastarla con la simulación numérica para decidir si el circuito hace lo que su nombre promete.

syms t s a w positive
laplace(exp(-a*t))                 % 1/(s+a)
laplace(t*exp(-a*t))               % 1/(s+a)^2
laplace(sin(w*t))                  % w/(s^2+w^2)

G = (s + 2)/(s^3 + 7*s^2 + 19*s + 13);
g = ilaplace(G);
g = simplify(g)                    % respuesta temporal del taller 7

%% Fracciones parciales con residuos numéricos
[r, p, k] = residue([1 2], [1 7 19 13])
% r: residuos | p: polos | k: término directo

%% Solución de la ecuación diferencial con condiciones iniciales
syms y(t)
Dy  = diff(y, t);
edo = diff(y, t, 2) + 12*Dy + 32*y == 32*heaviside(t);
sol = dsolve(edo, y(0) == 0, Dy(0) == 0);
sol = simplify(sol)                % 1 - 2*exp(-4*t) + exp(-8*t)

H = tf([1 2], [1 7 19 13]);

end

filtro_practica_final.m
%% Verificación de un filtro RC pasa-bajas (guion de la práctica final)
R = 1e3;  C = 1e-6;                 % componentes del esquemático
wc = 1/(R*C);
fprintf('Frecuencia de corte: %.2f rad/s (%.2f Hz)\n', wc, wc/(2*pi))

% 1. Modelo simbólico a partir del divisor de tensión
syms s t
Hs = (1/(s*C)) / (R + 1/(s*C));
Hs = simplify(Hs)

% 2. Respuesta temporal analítica ante escalón
y_escalon = ilaplace(Hs/s, s, t);
y_escalon = simplify(y_escalon)     % 1 - exp(-t/(R*C))

% 3. Modelo numérico y simulación ante impulso, escalón y rampa
H = tf(1, [R*C 1]);
t_sim = 0:1e-5:5e-3;

figure
subplot(1,3,1), impulse(H, t_sim), grid on, title('Impulso')
subplot(1,3,2), step(H, t_sim),    grid on, title('Escalón')
subplot(1,3,3), lsim(H, t_sim, t_sim), grid on, title('Rampa')

% 4. Contraste simbólico-numérico: el error debe ser despreciable
y_num = step(H, t_sim);
y_sym = double(subs(y_escalon, t, t_sim));
fprintf('Error máximo simbólico-numérico: %.2e\n', max(abs(y_num(:) - y_sym(:))))

% 5. Confirmación del tipo de filtro por su respuesta en frecuencia
figure, bode(H), grid on, title('|H(j\omega)|: cae 20 dB/década -> pasa-bajas')
